Crie um array chamado nomes com 5 nomes de pessoas. Peça ao usuário (via prompt) para digitar um nome. Verifique se esse nome existe no array: Se existir, mostre no console: "Nome encontrado!" Se não existir, mostre: "Nome não encontrado." Depois, adicione o nome digitado no array (independente se já existia ou não). Mostre no console a lista atualizada de nomes.
